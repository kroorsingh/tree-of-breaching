# Tree of Breaching

# **⚠️ WORK IN PROGRESS ⚠️**

A tool for Path of Exile 1 (patch 3.28) that finds the optimal **Genesis Tree** node allocation for crafting rare gear via Provisioning Wombgifts.

Paste your target item from PoE's advanced copy (Ctrl+Alt+C), set your point budget, and the optimizer recommends which Genesis Tree nodes to allocate to maximize your chances of hitting the mods you want.

**Stack:** Vite + React + TypeScript
